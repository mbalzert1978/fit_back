# Entscheidungen

Dieses Verzeichnis ist der einzige, ausschließliche Ort, an dem Entscheidungen und relevante
Neuerungen für dieses Repository festgehalten werden — siehe den Abschnitt „Entscheidungen und
Memory-Policy" in der [`CLAUDE.md`](../../CLAUDE.md) des Repos. Für dieses Repository wird von keinem
Assistenten, der darin arbeitet, ein externer oder sitzungsübergreifender Memory-Mechanismus
genutzt.

## Format

Eine Datei je Entscheidung: `YYYY-MM-DD-HHMM-<slug>.md`, mit Datum und Uhrzeit des Moments, in dem
die Entscheidung tatsächlich getroffen wurde (nicht des Datums, an dem sie später aufgeschrieben
wurde). Der Inhalt ist freiformig, sollte aber im Allgemeinen abdecken: was entschieden wurde,
warum, und was dadurch ausgeschlossen oder ersetzt wird.

## Sprache

Alle Dateien in diesem Verzeichnis werden auf Deutsch verfasst — siehe „Sprache der
Dokumentation" in der [`CLAUDE.md`](../../CLAUDE.md).
