# Decisions

This directory is the single, exclusive place where decisions and noteworthy changes for this
repository are recorded — see the "Decisions and memory policy" section in the repo's
[`CLAUDE.md`](../../CLAUDE.md). No external or cross-session memory mechanism is used for this
repository, by any assistant working in it.

## Format

One file per decision: `YYYY-MM-DD-HHMM-<slug>.md`, using the date and time the decision was
actually made (not the date it happened to be written up later). Content is free-form but should
generally cover: what was decided, why, and what it rules out or supersedes.
