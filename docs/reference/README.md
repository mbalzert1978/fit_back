# Reference

Lesenotizen zu **fremden** Quellen — Artikel, Muster, Bibliotheken —, die fuer dieses Repo
erwogen wurden. Eine Datei je Quelle.

Abgrenzung zu den Nachbarordnern:

- [`docs/decisions/`](../decisions/) haelt fest, was **entschieden** ist. Eine Datei hier haelt
  fest, was **gelesen** wurde und was daraus folgen koennte — die Entscheidung steht ggf. noch aus.
- [`docs/reflections/`](../reflections/) destilliert Lektionen aus **eigenen** Sitzungen.
- [`.rules/`](../../.rules/) ist verbindlich. Eine Notiz hier aendert dort **nichts**; wird ein
  Vorschlag angenommen, wandert er in die Regel und bekommt ein Decision-Doc.

Jede Datei nennt am Kopf die Quelle und traegt am Ende einen Abschnitt, der die Vorschlaege
sichtbar von den bereits erfuellten Punkten trennt und ihren Status benennt.
